# OuterMemory

## Goal

Build a stable memory layer independent of models and agents.

Memory > Agent > Model

---

## Principles

### Human Approval

AI can propose changes.

Only humans can approve changes.

### Traceable

All modifications must be traceable.

All modifications must be reversible.

### Agent Independent

Memory should work with any LLM.
